# Evidara V19.1 — Pricing and Super Admin Login As update

- Platform price: **₹199 per active student per year**.
- This fee is for Evidara platform access. Institution teachers maintain and update their question bank/content.
- Super Admin now has **Login As** role preview for Evidara Admin, School Admin, School Teacher and Student.
- Login As preserves the authenticated Super Admin Supabase session and changes only the effective application workspace/role for safe testing.
- **Return to Super Admin** restores the original Super Admin interface without sign-out/sign-in.
- Login As controls are visible only when the authenticated/base role is Super Admin.
