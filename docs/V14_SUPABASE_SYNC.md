# V14 Supabase Sync

This source targets **only** Supabase project `xzfozpnzvznqrvcsoail`.

The V14 migrations were applied directly through the connected Supabase project during development. Local marker files preserve those remote version numbers and prevent the source tree from appearing to predate the live database.

For a brand-new Supabase project, do **not** assume the V14 marker files alone bootstrap the database. The Evidara V13 migration history plus the V14 database objects must be exported/reconciled first.
